<Chapter n="i." label="Problem">

Short video is the cheapest distribution there is, but every 40 second clip still costs an hour of scripting, recording, finding footage and timing captions. I wanted to type "Arsenal vs Chelsea" or paste an article and get back a finished vertical video, **with a chance to fix the script before anything renders**.

</Chapter>

<Chapter n="ii." label="How it works">

<Steps
  caption="Fig. 2 · From topic to MP4"
  items={[
    ["Research", "A Claude agent reads the pasted link, searches the web and, for football, calls my Dixon Coles forecast"],
    ["Script", "The agent submits 4 to 8 scenes through a schema checked tool: narration, headline and a visual for each"],
    ["Edit", "Every line, visual and chart value is editable in the dashboard, with a live preview"],
    ["Voice", "ElevenLabs reads each scene and returns timestamps that drive word by word captions"],
    ["Render", "Remotion renders 1080 x 1920 at 30 fps H.264 in a worker process"],
  ]}
/>

- **Structured output, not free text.** The agent can only finish by calling `submit_script`, which is validated with zod and normalized before it reaches the editor.
- **Numbers come from tools.** In the football preset the agent is told to use odds only from the forecast tool, so the video never invents a probability.
- **Edit cost stays small.** Voice is cached per scene by content hash, so changing one line re-records one line.
- **Works without keys.** Demo mode falls back to the Mac's voice and animated backgrounds and still renders a real MP4.

</Chapter>
